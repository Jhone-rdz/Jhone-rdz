### 💬 Sobre mim

Sou desenvolvedor backend com foco em construir sistemas web robustos e escaláveis, unindo arquitetura multi-tenant, APIs REST bem desenhadas e modelagem sólida de dados. Trabalho principalmente com **Java (Spring Boot)** e **Python (Django/DRF)**, apoiado em **PostgreSQL**, **Docker** e infraestrutura **Linux** para levar soluções do banco de dados até o deploy. Atualmente meus projetos passam por diferentes domínios — gestão de produção leiteira, reservas de restaurantes, orientação vocacional com IA e sistemas para clínicas multiprofissionais — sempre com o mesmo objetivo: entregar código limpo, testável e pronto para produção.

### 💻 Technical Expertise (Hard Skills)

* **Backend Web Development:** APIs REST robustas e escaláveis com **`Java`** (**`Spring Boot`**) e **`Python`** (**`Django`** / **`Django REST Framework`**), com processamento assíncrono via **`Celery`** e **`Redis`**.
* **Arquitetura & Multi-tenancy:** Experiência prática com **arquitetura multi-tenant**, autenticação e autorização via **`JWT`**, controle de acesso baseado em papéis (**RBAC**) e aplicações **PWA offline-first**.
* **Database:** Modelagem de bancos de dados relacionais com **`PostgreSQL`**, incluindo diagramas DER (notação Crow's Foot/Mermaid), além de integração com **`Firebase`**.
* **Quality Assurance & Testes:** Testes unitários e automatizados com **`JUnit 5`**, **`Pytest`** e abordagem **BDD**, além de análise de qualidade de código com **SonarQube**.
* **DevOps & Infraestrutura:** Containerização com **`Docker`**, servidores web com **`Nginx`**, administração de sistemas **`Linux`**, versionamento com **`Git`**/**`GitHub`** e testes de API com **`Postman`**.
* **Frontend (apoio):** **`TypeScript`**, **`React`**, **`React Native`**, HTML5 e CSS3 para integração com APIs desenvolvidas.
